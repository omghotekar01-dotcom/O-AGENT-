GET STARTED

Guided setup

Connect only what you need. Each item has a clear verification step.

01

Install the desktop companion

On your trusted Windows laptop, install O-AGENT and launch O-AGENT.cmd. A local gateway registers your machine.

Connection check appears after login.

02

Enroll a project in VS Code

Open the actual repository folder in VS Code and install O-AGENT Workspace Companion 0.5.0. Click the O-AGENT icon in the left sidebar and choose Connect using Windows setup; approve the selected folder. No worker token typing is needed on the same Windows laptop.

Workspace verification appears after login.

03

Choose file permissions

Browsing is read-only by default. To edit text, locally run O-AGENT: Enable Mobile File Editing (30 minutes). Confirm each proposed change on your phone or this page.

Local editing permission is confirmed only inside VS Code. Check the laptop's O-AGENT sidebar.

04

Connect supported AI providers individually

Go to Connected tools to see which official adapter capabilities are available. Provider usage quotas, paid plans and private session restrictions still apply.

Provider status is checked live from the backend.
